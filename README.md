# РАССЛОЕНИЕ (Braintorm)

Сервис, который превращает живой созвон в структурированную карту мнений.

**Проблема.** На зум-встречах с одной темой обсуждение растекается: каждый приводит факты и боли, тезисы звучат, но команда не видит, какие темы вообще есть, и кто с чем согласен. Запись никто не пересматривает.

**Решение.** Второе окно звонка: модератор фиксирует тезисы, команда в реальном времени голосует (+1 / −1 / 0) и ведёт цепочки контраргументов под каждым тезисом. Разговор расслаивается на темы — в конце встречи остаётся карта: что обсуждали, что решено, где конфликт.

Рабочее название продукта: **«Расслоение»** — разговор расслаивается на темы.

## Что в репозитории

- `index.html` — интерактивный мокап второго окна (vanilla HTML/CSS/JS, открывается в браузере без сборки)
- `docs/concept.md` — продуктовая концепция и механики
- `docs/architecture.md` — целевая архитектура сервиса (ручной режим → автотранскрипт)
- `docs/roadmap.md` — поэтапный план MVP

## Статус

Ручной режим: модератор вводит тезисы вручную, звук не обрабатывается.
Мокап содержит симуляцию участников (голоса и комментарии появляются сами) для демонстрации «живой» доски.

## Быстрый старт мокапа

Открыть `index.html` в браузере. На экране входа ввести имя и отдел:
- роль **«Модератор»** — полный экран: заметки слева + доска справа;
- роль **«Участник»** — только общая доска.
